# AutoFloods documentation site (Quarto)

Built with [Quarto](https://quarto.org/) + [quartodoc](https://machow.github.io/quartodoc/)
(quartodoc generates `reference/*.qmd` from the `autofloods` package's
docstrings; Quarto renders the whole site to static HTML).

## Build

```bash
# one-time setup
pip install -e '.[docs]'      # from the repo root -- installs quartodoc + a compatible griffe
# install the Quarto CLI (not a Python package) if not already present:
#   https://quarto.org/docs/get-started/

cd quartodocs
quartodoc build                # generates reference/*.qmd from docstrings
quarto render .                 # renders the full site to _site/
```

Open `_site/index.html`, or `quarto preview .` for a live-reloading local
server while editing.

`reference/` is regenerated by `quartodoc build` every time -- it's
gitignored, not hand-edited. `index.qmd` and `getting-started.qmd` are
hand-written and should be edited directly.

## Publishing

Not yet wired to GitHub Pages / any hosting. `quarto publish gh-pages`
(run from `quartodocs/`) is the standard path if/when this project wants
that -- see [Quarto's publishing docs](https://quarto.org/docs/publishing/).
